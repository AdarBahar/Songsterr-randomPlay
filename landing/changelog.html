Changelog

What changed in each version of the extension. Full release notes and downloads live on GitHub Releases.

v1.6.2

2026-10-26Latest

Inbox Badge Fix

  • 🔧 Badge mix-up fixed — Songsterr added an unread-count badge to the toolbar's Inbox item; the Random button briefly showed "Random" in a red badge over an "Inbox" label
  • 🏷️ Correct label and icon — the button again shows the shuffle icon with the "Random" label, with no badge

v1.6.1

2026-10-08

Songsterr Bottom Bar

  • 🔧 New Songsterr layout — Songsterr moved its navigation to a floating bottom bar; the Random button now joins that bar, styled like the native items
  • 🎨 No more "selected" look — the button no longer inherits the active-tab highlight
  • ⌨️ Shortcut feedback — pressing the shortcut key flashes the Random button with the same green look as hovering it
  • 🖼️ Icon sized to the bar — the icon now matches the size of Songsterr's own icons

v1.6.0

2026-10-04

Firefox Support & Fixes

  • 🦊 Firefox version — the extension is now on Firefox Add-ons (Firefox 140+)
  • 🎲 Repeat avoidance fixed — song history and the favorites cache now survive each play's page navigation
  • ⌨️ Shift + shortcut fixed — force refresh now works for symbol and letter keys
  • 🔍 Button re-injection — the button comes back after Songsterr re-renders its toolbar
  • ⚙️ Settings fixes — changing one setting no longer risks reverting another; a snackbar confirms every save; custom slider values survive preset switches
  • 🧾 Active settings at a glance — randomization and instrument shown in the popup, the button tooltip, and the loading notification
  • ⚖️ Fairer shuffle — no immediate repeats in small libraries; favorites with identical dates get equal odds

v1.5.0

2026-06-17

Instruments, Weighted Randomization & Redesign

  • 🎯 Preferred instrument — open the Guitar, Bass, or Drums track when available, else the default track
  • 🎲 Weighted randomization — favor newly added and/or least-played favorites, with presets and custom sliders
  • 🗂️ Full settings page — a dedicated options tab; the popup slimmed to a launcher
  • 🎨 Redesigned UI — dark theme, bundled fonts, segmented controls, animated equalizer
  • 🔌 Sturdier favorites — favorites now come from Songsterr's JSON API instead of page scraping
